<details>

<br/>

I'm currently interested in building systems that combine:

- Modern full-stack development
- Well-designed databases
- Workflow automation
- AI coding agents
- Clean infrastructure
- Practical UX for real operational problems

I especially enjoy projects where software replaces complicated manual processes.

</details>

<details>
<summary><b>⚙️ How I like to build software</b></summary>

<br/>

```text
Understand the problem
        ↓
Model the workflow
        ↓
Design the architecture
        ↓
Design the data
        ↓
Build the smallest useful version
        ↓
Test with real workflows
        ↓
Iterate
        ↓
Ship
```

</details>

<details>
<summary><b>🧩 My engineering principles</b></summary>

<br/>

engineering:
